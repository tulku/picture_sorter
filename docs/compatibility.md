# Compatibility and qualification

Normal startup and `doctor` never probe or mutate NAS objects or application state. Production publication and outgoing ratings are disabled until matching evidence exists. Normal reads, local saved-edit capture and private pins continue independently. The local test backend is explicit and rejects network filesystems; it never supplies production evidence.

| Capability | Automated evidence | Deployment requirement |
|---|---|---|
| Linux publication | Actual exclusive creation, no-replace, exchange, lock exclusion, flush/reopen on generated temporary files | Run the same probe on a separate explicit scratch directory on the target mount |
| Multiple publishers | Independent daemon tests on an explicitly local test archive | Distinct machines/writer IDs, peer handoff, disconnect observation and positive shutdown/quiescence; single-client results cannot enable this mode |
| RapidRAW 1.6.6 | Source-backed native schema, ratings, default/reset, unknown fields and masks | Supply native saves, reopened and reset-regenerated documents from the installed binary; attest the isolated runtime steps |
| RapidRAW inspected development revision | Source-backed adapter tests | Exact matching version/binary and native runtime validation |
| Immich 3.3.5 | Synthetic HTTP schema, nullable-zero PUT/readback, uncertainty and identity tests | Run an explicitly authorized isolated JPEG asset probe against the installed server |
| Other application versions | Opaque edit capture remains available | Transformations and outgoing rating writes remain disabled until a supported adapter and matching qualification exist |

`qualify --request /absolute/request.json` submits a durable qualification job. JSON requests are tagged `{"kind":"nas|rapidraw|immich","request":{...}}`; the tagged kind is one of those strings. Unknown fields are rejected. CLI output includes the report, whether it qualifies, and the immutable local evidence path. Completed but incomplete qualification exits 3; failed checks exit 4. Failed evidence replaces the active report for the same fingerprint while retaining history. Reports and the active registry require owned regular mode-0600 JSON files.

NAS requests require `archive_root`, `archive`, `writer`, `mode`, `mode_revision`, `scratch_root`, `session`, `phase`, `local_test_backend`, `prior_peer_stopped`, `all_writers_quiescent`, `disconnect_observed`, and `interrupt_bytes`. Mode values are `SingleWriter`, `MultiWriter`, `LocalTest`; phases are `prepare`, `peer`, `verify`. Scratch must be separate from all managed roots and on the same mounted filesystem as the archive. Use a fresh session UUID; interrupted or unknown scratch contents are retained, never adopted blindly. Start Prepare on client A, run Peer with a distinct writer on client B, then Verify on A. For disconnect qualification, interrupt B's explicitly owned scratch write, disconnect/reconnect as applicable, positively stop its process group, and verify quiescence before setting the three observation flags. These flags are operator assertions, not inferred from timeouts. Artifacts remain under `.photo-sorter-qualification/<session>` in scratch. No real NAS or second-client test was run by the automated build.

Editor requests require `isolated_root`, `version`, relative document paths `before`, `three`, `five`, `zero`, `reopened`, `regenerated_after_reset`, optional `runtime_binary`, and `runtime_saves_attested`. Create the native saves in an isolated fixture, preserving adjustments, masks and unknown fields while changing only ratings. Reopen the zero save, then regenerate a default document after Reset. The validator compares the supplied documents without launching the editor. Source-only documents do not enable runtime transformations. A runtime report binds the executable digest and configured version; executable replacement invalidates the service's captured identity and requires restart/requalification. Configure the exact `rapidraw_binary` path. The service caches a strong binary digest at startup and checks device, inode, size, mtime and ctime before accepting its runtime identity.

Immich requests require `origin`, `key_file`, `asset`, `isolated_asset_confirmed:true`, and `fixture`. Origin and secret file must match the profile. Fixture scope is restricted to an exact asset on an IP loopback origin. The probe validates server/schema/JPEG identity, exercises 0→3→5→0 with GET readback, and restores the original rating using the last confirmed value as precondition. An uncertain/conflicting result stops further writes, retains failed evidence, and requires inspection of the isolated asset. Logical zero uses JSON null for the pinned API. The API has no compare-and-set: a change between GET and PUT can still race. Runtime use additionally requires explicit `best_effort` mode. No personal asset is selected automatically.

Archive modes default to SingleWriter and bind one writer ID. `archive change-mode --request /absolute/mode.json` is explicit administration. A request includes `operation`, the complete `expected` marker, `mode`, `new_owner`, `all_writers_quiescent`, `prior_owner_stopped`, `no_unresolved_io`, and `recover`. All three assertions must be true. Qualify the target writer/mode/next revision first. The shared publication lock protects an immutable versioned administration journal under `.photo-sorter/modes`, a pending intent, and an atomic marker exchange that preserves the displaced marker. Interrupted updates block publication. After positively stopping all old publishers and proving no unresolved I/O, repeat the exact request with `recover:true`; another operation cannot adopt its pending intent. No deadline authorizes lock takeover. LocalTest mode is unavailable on production root handles.

Mount identity, archive ID, writer ID, mode revision and implementation version invalidate filesystem reports when changed. Immich origin/server version invalidate rating reports. A report is evidence for the exact tested scope, not a hardware durability warranty; flush/reopen does not simulate NAS power loss. Keep writes disabled for unrun or failed capabilities.
